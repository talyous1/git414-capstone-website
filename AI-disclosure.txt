Google AI was used to give an example of a preference query. I took inspiration from its results:

🎨 Visual & Theme Preferencesprefers-color-scheme: Detects if the user prefers a light or dark interface.css@media (prefers-color-scheme: dark) {
  body {
    background-color: #121212;
    color: #ffffff;
  }
}
Use code with caution.prefers-contrast: Detects whether the system is set to increase or decrease color contrast (no-preference, more, less, custom).css@media (prefers-contrast: more) {
  button {
    border: 2px solid black;
  }
}
Use code with caution.forced-colors: Detects if the operating system restricts the page to a limited, user-selected color palette (like Windows High Contrast Mode).prefers-reduced-transparency: Used to detect if the user wants to reduce translucent background effects for better readability (no-preference, reduce). [1] (https://www.sarasoueidan.com/blog/prefers-color-scheme-browser-vs-os/), [2] (https://css-tricks.com/a-complete-guide-to-css-media-queries/), [3] (https://daily.dev/posts/the-four-user-preference-media-queries-your-css-should-honor-d3p1sn2t2)🏃‍♂️ Motion & Performance Preferencesprefers-reduced-motion: Detects if the user has requested to minimize animations, transitions, or flashing content (no-preference, reduce).css@media (prefers-reduced-motion: reduce) {
  * {
    animation-duration: 0s !important;
    transition-duration: 0s !important;
  }
}
Use code with caution.prefers-reduced-data: Detects if the user wants to conserve data usage, allowing you to avoid loading heavy background images or videos (no-preference, reduce).
