# Behavior Annotations

- For this website, a hamburger menu will be needed for the navigation. It will require the navigation to appear and then go back to hiding. This hamburger will be required for smaller viewport views. 
- The website will need to be responsive to different viewport sizes. For the home page, the in-class image and the upcoming events text section will be side-by-side. For smaller viewport sizes, they must stack instead of being side-by-side. 
- The information paragraph and the breakdown table on the tuition page will have to change from being side-by-side to being stacked for smaller viewport sizes. 
- For all other elements, they will simply resize to fit the page. All of the resizing will be done using media queries in CSS. 
- Repeated components will be the logo, navigation bar, and footer. 
- There will be a form on the contact us page. To receive the results for this form, the free form data endpoint, formsubmit.co, can be used for the action. The method will be set to post.
