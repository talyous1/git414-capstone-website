# Typography
Noto Serif is used for headings, with the fallback of Serif. Roboto is used for the body, with the fallback of Sans-serif. These are HTML fonts. Headings are 2rem, subheadings are 1.5rem, and body text is 1rem.

# Optimization Risks
The three assets most likely to affect performance, accessibility, or layout shift are the three images. Out of these three, the hero image of the school building would the most, as it takes a lot of space and goes from being quite large on a computer to small on a phone.

# Evidence Plan
I will run a lighthouse report via the Chrome Inspection tool to see if my website has any issues in terms of file size, dimensions, responsive behavior, loading, or accessibility. I will also use the Chrome Inspection tool to view the site across different viewport sizes, as well as manually resize my window and use the zoom tool.
