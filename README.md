# Advanced American Academy
My GIT 414 capstone: a 4-page website for a fictional K-12 school in Houston, Texas, made with HTML and CSS.

Live Site: https://talyous1.github.io/git414-capstone-website/

## Pages:
- index.html: about the school, programs, and events
- admissions.html: enrollment steps
- tuition.html: fees by grade
- contact.html: contact form (results through FormSubmit)
## Built with:
This capstone is built with semantic HTML and one stylesheet with 7 cascade layers and tokens. The layout uses grid, subgrid, a container query, and clamp(). Photos use srcset, and every page has its own title, description, and canonical.
## Testing:
I tested the live website with HTML, CSS, and link validators, axe, Lighthouse, keyboard navigation, zoom, and screen sizes from 320 to 1280px. Evidence is saved in its own folder in this repo.
## Known limitations:
There is no hamburger menu or custom form messages (both need JavaScript). There are some render-blocking fonts and layout shift.
