# Site Map & Page Requirements

## Page Relationships

The home page is the main landing page. On every page, users should be able to navigate to the home page, admissions page, tuition page, or contact us page. All pages should be accessible regardless of the page a user has open. 

## Purpose of each page

- Home
  - Purpose: Convey information about the school's mission, vision, and offered programs. 
  - Key content: Headers, paragraphs, and images about the school. 
- Admission
  - Purpose: Convey information about the school's enrollment process.
  - Key content: Headers and paragraphs about how to enroll. An "enroll now" link.
- Tuition
  - Purpose: Convey to parents a breakdown of the school's billing.
  - Key content: Headers, paragraphs, and a table breaking down the costs a parent can expect.
- Contact Us
  - Purpose: Allow users reach out or submit a question to school admin. 
  - Key content: A fully functional form.

## Content Risks to Resolve

1. Ensure that all headers are in proper heading order.
2. Ensure that any images used are free to use or are property of the organization itself.
3. Ensure that all links are properly named and formatted, and will not break easily.
