# Project Brief

## Site Purpose
The purpose of this website is to convey information about a K-12 Non-profit private school organization. It must communicate details about the school's offerings, as well as communicate how to enroll, as well as associated parent costs.

## Primary Audience
The primary audience for this website will be parents that are currently involved in the school, as well as new interested parents.

## Primary User Tasks

1. Visit the homepage and learn about the school
2. Navigate to the admissions and tuition pages and read information on those pages.
3. Navigate to the contact us page, and be able to submit a contact form.

## Constraints
- Website must be accessibility-friendly
- Website must pass HTML, CSS, and other validators with no errors
- All pages must be responsive to different viewport sizes

## HTML/CSS Scope
This website will need 4 html files. An index file, admissions, tuition, and a contact us file. It will need one CSS stylesheet file. Must use HTML and CSS only. Will need to use basic HTML and CSS syntax and include forms, flexbox, media queries, nav, and tables. The website will also need an endpoint for form responses, in this case formsubmit.co will be used.
